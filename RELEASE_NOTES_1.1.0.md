# Nyxoryth Calculator 1.1.0

Nyxoryth 1.1.0 is the first full release of the expanded screen-based calculator interface.

## Highlights

- Three-bar screen navigation instead of side-by-side mode panels
- Resizable/maximizable window with persistent size
- Optimized animated GIF background rendering
- Scientific+
- Statistics
- Fractions / GCD / LCM
- Equation Solver
- Complex Numbers
- Unit Converter
- Date / Time Tools
- Advanced Bit Tools
- Computer / Storage Math
- Improved validation across the new calculation screens
- Screen-aware keyboard shortcuts

## Keyboard

- `Alt+M` — screen menu
- `F6` — focus the primary input
- `F5` — run the active screen's primary action
- `Enter` — context-aware calculation from single-line tool inputs
- `Ctrl+Enter` — Statistics calculation
- `F1` — About
- `Ctrl+C` — copy calculator result when appropriate

## Privacy

Nyxoryth remains local/offline:
- no telemetry
- no cloud calculation
- no online accounts
- no network API used by the calculator features

## Background media

Nyxoryth does not ship user background images, GIFs, JPEGs, PNGs, BMPs, or fonts. Background files are selected locally by the user.
