# Security Policy

## Reporting a vulnerability

Please report suspected Nyxoryth security vulnerabilities privately by email:

**Queen3K@proton.me**

A useful report includes:

- Nyxoryth version
- Windows version
- steps to reproduce the issue
- what you expected to happen
- what actually happened
- the potential security impact
- screenshots or logs when useful

Please avoid publishing sensitive exploit details before the issue has been reviewed.

## Scope

Nyxoryth is designed as a local/offline Windows calculator. Relevant reports can include, for example:

- unsafe handling of local files or background paths
- crashes caused by malformed inputs that may have a security impact
- unintended file writes or reads
- privilege, process, or memory-safety issues
- release/package integrity issues

General feature requests and ordinary calculator bugs can be reported separately from security reports.
