# Nyxoryth 1.1.0 Release Checklist

## Build / version
- Run `./Build/Build_Nyxoryth.bat`
- Confirm `BuildOutput/Nyxoryth.exe` exists
- About shows `1.1.0`
- EXE Properties -> Details shows Product version `1.1.0`

## Regression
- Standard, Scientific, Tip, Programmer, History, Settings still work
- Dark/Light mode still work
- PNG/JPG/BMP backgrounds still work
- Animated GIF background still plays without control/background flicker
- Moving/resizing the app remains smooth
- Maximize / restore / saved window size still work
- Three-bar navigation opens every screen

## Keyboard
- `Alt+M` opens the screen menu
- `F6` focuses/selects the primary input on a tool screen
- Statistics: plain Enter inserts a new line; `Ctrl+Enter` calculates
- Statistics: `F5` calculates
- Fractions: Enter in a fraction input performs A + B
- Equation Solver: Enter in linear inputs solves linear
- Equation Solver: Enter in quadratic inputs solves quadratic
- Complex Numbers: Enter in a number input performs z1 + z2
- Units: Enter in the value/rate input converts
- Date/Time: Enter runs the action matching the focused field
- Programmer: Enter runs the matching tool for the focused field
- Bit Tools: Enter converts; Unicode field Enter performs lookup
- Computer Math: Enter runs the focused input group
- F1 opens About

## Validation
- Statistics `1, 2, nope, 4` reports the invalid value instead of calculating partial input
- Statistics empty input reports that at least one number is required
- Fraction A denominator `0` explicitly reports denominator cannot be zero
- Fraction non-integer text reports the specific bad numerator/denominator
- Linear equation with extremely large finite coefficients fails cleanly if the result overflows
- Quadratic extreme values fail cleanly instead of showing `inf`/`nan`
- `arg(0 + 0i)` reports undefined
- Unit temperature below absolute zero is rejected
- Manual Rate `0` and negative rates are rejected
- An 8-bit positive bit-tool input larger than 255 reports that masking occurred
- Computer Math invalid unit/RAID selections do not silently return
- Bitrate/file-size overflow reports an error
